# Barbershop: сайт барбершопа с управлением каталогом

Сайт с услугами, ценами и карточками мастеров. Администратор может менять каталог через интерфейс: добавлять услуги, редактировать стоимость и загружать фотографии мастеров.

Учебный fullstack-проект на React и Express. Здесь можно посмотреть работу с формами, Redux Toolkit, REST API, загрузкой файлов и MySQL через Sequelize.

## Что сделано

- Главная страница с услугами, мастерами, контактами и картой.
- Добавление, изменение и удаление услуг и мастеров.
- Несколько цен для одной услуги и указание её длительности.
- Загрузка фотографий на сервер и хранение данных в MySQL.

## Как устроен проект

| Папка | Назначение |
| --- | --- |
| `client/src/components` | Разделы сайта и формы редактирования |
| `client/src/store` | Состояние интерфейса и запросы через Redux Toolkit |
| `server/routes` | Маршруты Express |
| `server/conrollers` | Обработка запросов и операции с каталогом |
| `server/db` | Подключение MySQL и модели Sequelize |

Браузер обращается к API на порту 3001. API сохраняет записи в MySQL, фотографии складывает в `server/static`. Таблицы создаются при первом запуске.

## Запуск

Нужны Node.js 24, npm и Docker с Compose. Команды выполняются из корня репозитория.

```bash
git clone https://github.com/kvantoniY/barbershop.git
cd barbershop
cp server/.env.example server/.env
docker compose up -d --wait
npm ci --prefix server
npm ci --prefix client
npm run seed --prefix server
npm start --prefix server
```

Во втором терминале:

```bash
npm start --prefix client
```

Откройте http://localhost:3000. API каталога: http://localhost:3001/services. MySQL доступен на локальном порту 53306.

В Windows PowerShell используйте `Copy-Item` вместо `cp`. Если PowerShell блокирует `npm.ps1`, запускайте `npm.cmd` вместо `npm`.

## Что проверить

1. Откройте главную: должны появиться услуги и мастера из демо-каталога.
2. Перейдите на `/admin`, войдите с логином `demo` и паролем `demo123`.
3. Добавьте услугу, измените цену, обновите страницу. Изменения должны сохраниться.
4. Добавьте мастера с фотографией и проверьте его карточку.

Сборка клиента: `npm run build --prefix client`. Результаты проверки: [docs/VERIFICATION.md](docs/VERIFICATION.md).

## Ограничения

Авторизация администратора в этой ранней версии учебная. Серверные операции каталога не защищены полноценной проверкой прав. Запускайте проект локально; для рабочего сайта нужно доработать авторизацию и хранение паролей. Кнопка записи не создаёт бронирование.
