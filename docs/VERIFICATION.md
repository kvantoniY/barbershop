# Проверка запуска

Дата: 6 ноября 2026 года. Окружение: Windows, Node.js 24.15.0, npm 11.13.0. Для серверных баз использован Docker Desktop. Проверка выполнена в отдельной копии репозитория с локальными данными.

## Результаты

- Зависимости установлены через `npm ci`.
- Production-сборка клиента завершилась успешно.
- API запущен и отвечает на запросы.
- Веб-сервер отдаёт HTML и JavaScript-файлы с кодом 200.

Проверены демо-каталог, вход администратора, создание и удаление услуги. Авторизация остаётся учебной, развёртывать эту версию в открытом интернете не следует.

## Проверенные запросы

```text
GET /services: 200
POST /services/add: 200
GET /services: 200
POST /services/delete: 200
GET /services: 200
POST /admin/login: 200
```

## Повторить проверку

Запустите проект по README. В отдельном терминале из корня репозитория выполните:

```bash
node scripts/smoke.mjs
```

Скрипт обращается только к локальному API. Он создаёт демонстрационные записи и проверяет сохранение данных. Для проверки используйте отдельную локальную базу.

## Что эта проверка не покрывает

Проверка HTML и API не заменяет ручной проход по всем экранам. Визуальное оформление, мобильная версия и все пользовательские действия в браузере в этот прогон не вошли. В старых проектах остаются предупреждения линтера и устаревшие зависимости. Полный аудит безопасности не проводился.
